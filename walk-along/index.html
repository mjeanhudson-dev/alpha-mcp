Questions

How the SQLite vault handles secrets, disk images and MCP clients.

Email the maintainer

Does Alpha MCP upload files or secrets?

No. Hashing, nine-rule redaction and FTS5 writes run locally in Python 3.10+.

How does Alpha MCP inspect .vhdx and .zip archives?

Inspect mode calls 7-Zip list output and zipfile without unpacking disk images.

What does Alpha MCP leave out by design?

No neural embeddings or cloud cluster; only BM25 keyword and Python AST search.

Which MCP clients query the SQLite vault?

Claude Code, Codex and Antigravity query the read-only WAL database via stdio.

How do teams keep vaults out of Git?

Ignore SQLite and archive files in .gitignore and run the pre-push hygiene gate.
